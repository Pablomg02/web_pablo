# Privacidad

En esta web sigo una ética de privacidad sencilla: no recoger información privada y no dejar que rastreadores de terceros la recojan aquí.

La web usa GoatCounter únicamente para saber si recibe visitas y qué páginas se leen. El propósito es tener analíticas básicas y respetuosas con la privacidad, no identificar a nadie. GoatCounter no usa cookies ni almacenamiento del navegador, no guarda direcciones IP, cabeceras User-Agent completas ni identificadores de seguimiento, y no comparte información con terceros.

En esta web, GoatCounter guarda solo las señales mínimas que me resultan útiles: visitas a páginas, sitios de procedencia, país o región y sesiones de corta duración. He desactivado el registro individual de páginas vistas, los datos de navegador y sistema derivados del User-Agent, el tamaño de pantalla y la recogida del idioma. El país y la región se obtienen antes de guardar nada, sin almacenar la dirección IP.

Las sesiones están activadas para que una recarga o una vuelta a la misma página no cuente cada vez como una persona nueva. GoatCounter lo hace sin guardar tu dirección IP: asocia temporalmente la web, la dirección IP y el User-Agent a un UUIDv4 aleatorio en memoria durante un máximo de 8 horas. La dirección IP y el User-Agent no se escriben en la base de datos ni en disco, y el UUID aleatorio no permite recuperarlos. Puedes leer la [explicación de las sesiones](https://www.goatcounter.com/help/sessions) de GoatCounter.

También puedes leer la [política de privacidad](https://www.goatcounter.com/help/privacy) de GoatCounter y su [aviso de consentimiento del RGPD](https://www.goatcounter.com/gdpr).

Por supuesto, puedes usar bloqueadores de rastreadores o herramientas de privacidad cuando visites esta web.

Aparte de GoatCounter, esta web no usa cookies publicitarias, formularios de contacto, rastreadores de marketing de terceros ni fuentes alojadas externamente.

El único almacenamiento del navegador que usa esta web directamente es *localStorage*, que recuerda si prefieres el tema claro o el oscuro.

La web está alojada en GitHub Pages. GitHub puede tratar los datos técnicos necesarios para prestar y proteger el servicio. Consulta la [recogida de datos de GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/about-github-pages#data-collection) y la [Declaración de privacidad de GitHub](https://docs.github.com/en/site-policy/privacy-policies/github-privacy-statement).
